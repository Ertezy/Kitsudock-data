# Kitsudock-data

Раньше проект назывался Gacha Hub, а этот репозиторий — Gacha-hub-info.

Данные для панели лаунчера Kitsudock: промокоды, баннеры персонажей и видео
Genshin Impact, Honkai: Star Rail, Zenless Zone Zero, Wuthering Waves и
Arknights: Endfield.

Файл собирается автоматически раз в час:
https://ertezy.github.io/Kitsudock-data/hub.json

Не связано с разработчиками игр. Материалы принадлежат правообладателям.

Новости Wuthering Waves на официальном сайте Kuro Games запрашиваются раз в
6 часов: сборщик читает анонсы баннеров и патчноуты и берёт из них только
факты — название баннера, имя 5★ резонатора, даты и конец техработ версии.
Так новый баннер персонажа появляется в панели в день анонса, ещё до страницы
на вики; его `url` ведёт на сам анонс, а картинка — арт прошлого запуска с
фандома (см. ниже). Как только фандом
создаёт страницу (то же название, начало в пределах двух суток; регистр,
кавычки и лишние пробелы не в счёт), в файл идёт запись фандома. Текст статей и
картинки Kuro не копируются и не хранятся. Оружейные баннеры и оружейные
анонсы не берутся. Читаются анонсы не старше 21 дня; факты прочитанного анонса
остаются в памяти, пока идёт хотя бы один его баннер, даже если анонсу уже
больше 21 дня.

У каждого кода есть ссылка на страницу-источник (`source`), у каждого баннера —
ссылка на страницу вики или на официальный анонс (`url`). Картинки не хранятся:
в файле только ссылки.

Раз в 6 часов сборщик узнаёт номер последней опубликованной версии приложения и
кладёт его в поле `app` (`{ "version": "0.1.1", "url": "…/releases/tag/v0.1.1" }`):
по нему приложение показывает «Вышла версия». Черновики и пробные версии не
учитываются; пока опубликованных релизов нет, поля нет.

Раз в 6 часов сборщик берёт у официального лаунчера HoYoPlay ссылки на текущий
фон Genshin Impact, Honkai: Star Rail и Zenless Zone Zero — первый фон каждой
игры: картинку и, если фон видео, ролик — и кладёт их в `games[].background`.
Сами картинки и ролики нигде не хранятся.

Тем же путём, тоже раз в 6 часов, идут официальные соцсети Genshin, Star Rail и
ZZZ: значки из окна лаунчера на русском и английском. Сборщик кладёт их в
`games[].socials` как `{ "ru": [{ "kind": "vk", "url": "…" }], "en": […] }` в
порядке окна лаунчера, не больше 10 на язык. Тип записи — по хосту адреса, а у
короткой ссылки `hoyo.link` — по тому, куда она ведёт (один запрос без перехода
по ней); в `url` остаётся сама короткая ссылка. Чаты поддержки (WhatsApp,
Messenger) и всё, чего нет в списке типов, пропускаются. Запросы идут подряд,
с паузой между ними; не вышло — остаётся прошлый список. У Wuthering Waves и
Arknights: Endfield списки заданы в коде по их официальным сайтам. Перед
выкладкой каждая запись проверяется: тип из списка, хост подходит к типу,
простой публичный https-адрес до 512 знаков.

Если у баннера картинки нет — вики назвала файл нового запуска, но ещё не
загрузила его, или баннер взят из анонса Kuro, — ставится самый свежий арт с тем
же названием баннера с фандома этой игры («Название.png» или «Название
2026-05-21.jpg»): название баннера закреплено за персонажем, и на прошлых
запусках он тот же. Каждый такой баннер перепроверяется раз в 6 часов; когда
вики загрузит файл нового запуска, в файл идёт он.

Файл данных распространяется по лицензии CC BY-SA 4.0.

Коды Arknights: Endfield автоматически не собираются: открытого источника со
сроками нет. Их можно вписать в файл правок.

## Файл правок

`overrides.json` — чтобы добавить код или баннер, которого источники ещё не
знают, или скрыть ошибочную запись. Правится прямо на сайте GitHub: открыть
файл, нажать карандаш, сохранить. Через пару минут правка попадёт в данные.

```json
{
  "codes": [
    { "game": "endfield", "code": "ENDFIELDGIFT", "rewards": "150 Oroberyl", "expires": "2026-10-01 23:59 UTC+8" }
  ],
  "banners": [
    { "game": "wuthering", "title": "Thousand Futures Mirrored in Snow", "featured": ["Hiyuki"],
      "starts": "2026-09-10 10:00 UTC+1", "ends": "2026-09-29 11:59 UTC+1" }
  ],
  "hide": [
    { "game": "genshin", "code": "WRONGCODE" },
    { "game": "wuthering", "banner": "Название баннера" }
  ]
}
```

- `game`: `genshin`, `hsr`, `zzz`, `wuthering`, `endfield`.
- Время — строкой с поясом: `2026-10-01 23:59 UTC+8`. Срок кода можно не писать.
- Сроки баннеров показываются по европейскому серверу (UTC+1).
- Сгоревшее выпадает само, чистить файл не нужно.
- Ошибку в файле покажет красный крестик у коммита; сбор при этом не ломается.

Проверить сборщик локально, не публикуя результат: `npm run collect -- --dry-run`
(флаг обязательно после `--`, иначе npm его проглотит и запуск станет боевым).

## Задачи с меткой «сборщик»

Сборщик сам открывает задачи и сам их закрывает:

- **Не работает: …** — источник не отвечает или поменял разметку. Пока он
  сломан, в файле остаются прошлые данные.
- **Анонс баннера Wuthering Waves не разобрался** — вышел официальный анонс
  баннера персонажа, но сборщик не смог прочитать из его статьи название и сроки.
  Задача появляется, только если самый свежий такой анонс (не старше 21 дня,
  оружейные не считаются) прочитан и не дал ни одного баннера — в том числе если
  сайт ответил, но текста статьи в ответе нет; статья, которую не удалось открыть
  (сбой сети, ошибка сайта), задачи не даёт. Впишите баннер в `overrides.json`:
  если начало вписанного баннера Wuthering Waves не раньше чем за двое суток до
  выхода самого свежего анонса, задача закрывается на следующем прогоне. Закрывается
  она и сама, когда анонс удалось разобрать, вышел более новый анонс или этому
  исполнился 21 день.
- **Файл правок не читается** / **Файл данных не прошёл проверку**.
- **Сделай любой коммит: расписание скоро выключится** — GitHub выключает
  расписание после 60 дней без активности в репозитории.
